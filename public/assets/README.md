# Assets — Passe Booyah

As imagens principais serão inseridas aqui posteriormente. Salve os arquivos com
estes nomes para que sejam carregados automaticamente pela landing page:

## 1. `banner-booyah.webp`

- **Uso:** imagem principal do hero/banner.
- **Composição:** personagem em primeiro plano, cenário futurista, explosão/iluminação
  amarela ao fundo, tons de roxo.
- **Formato sugerido:** WebP (ou AVIF), proporção vertical cinematográfica (~3:3.4).
- **Tratamento no CSS:** `object-fit: cover; object-position: center;`.

## 2. `passe-booyah.webp`

- **Uso:** ilustração do cartão de Passe Booyah no card de recompensas.
- **Composição:** cartão raro de jogo, borda dourada, brilho amarelo/roxo, símbolo central.
- **Formato sugerido:** WebP com fundo transparente (ou recortado), proporção próxima
  de um cartão (~2:3).
- **Tratamento no CSS:** `object-fit: contain;` com leve perspectiva (`rotateY/rotateX`).

Nenhuma alteração de código é necessária após adicionar os arquivos.
